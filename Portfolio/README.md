# Aarav Shah — Portfolio

A responsive personal portfolio covering FTC robotics, Python market research, music, community leadership, awards, skills, and coursework.

## Live website

[aaravshahportfolio.vercel.app](https://aaravshahportfolio.vercel.app)

The Vercel project should use `Portfolio/` as its Root Directory. This repository keeps the app in that folder so the portfolio source and its deployment configuration stay together.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run build
npm run lint
```
